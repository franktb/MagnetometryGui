Saving a project
==============

To save the current project, select {\em Save Project} within the drop-down menu {\em File} (see Fig.\ref{fig:drowdown_import}).
This will open a file dialogue.
Within the file dialogue navigate to the desired location.
The location should be an empty folder which could be arbitrary named.
Within this folder the following will be created:
\begin{itemize}
	\item A \verb|project_name|.json file containing the project structure and meta information.
	\item A folder for each survey containing all associated survey frames as parquet.
\end{itemize}
