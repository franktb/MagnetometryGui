Downward continuation for fixed depths
======================================

As illustrated in :ref:`sec:DownwardOverview`, the integral estimates the magnetic field for a surface at a given depth.
Currently, the user can select between whether the field should be estimated at a single layer or for multiple layers using the combo box provided on the right hand side.

If ``Layers`` has been selected the input field below become effective.
Here, the minimal and maximal depth as well as the desired depth resolution can be configured as well as the displayed layer can be selected.
